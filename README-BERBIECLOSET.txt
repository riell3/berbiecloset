BERBIECLOSET WEBSITE SOURCE

This archive contains the BERBIECLOSET website project files from its current Higgsfield-hosted version.

Project location: app/
Stack: React 19 + TanStack Start + TypeScript + Vite, configured for Cloudflare Workers.

IMPORTANT: This is the complete project source, not a one-click static HTML upload. It uses a Cloudflare Worker/TanStack server runtime and platform bindings. A different host may require adapting the deployment configuration and runtime features before it can run there. Keep the current live site available until a replacement has been tested.

To work on it, use the package scripts in app/package.json and the existing lockfile. Do not upload secrets or credentials into source files.
